Help

      
Panduan ringkas MastaXul Webmaster Manager.

    

  


  


    

      SEO Score
      

        Score dikira oleh Worker berdasarkan pemeriksaan SEO asas seperti
        title, meta description, canonical, robots, viewport, H1,
        JSON-LD, favicon dan Open Graph.
      

    


    

      Google Search Console
      

        Google perlu OAuth. Akaun Google mesti mempunyai akses kepada
        property Search Console. Token disimpan di Cloudflare KV,
        bukan dalam browser.
      

    


    

      Google URL Inspection
      

        Pilih property terlebih dahulu. URL yang diperiksa perlu
        berada di bawah property tersebut.
      

    


    

      Google Search Analytics
      

        Pilih tarikh dan dimension seperti query, page, country,
        device atau date. Data datang daripada Search Console API.
      

    


    

      Bing ThrottleIP
      

        Bing boleh mengehadkan request daripada IP tertentu.
        Jangan tekan Refresh Sites berkali-kali apabila ErrorCode 17
        muncul. V4.4.0 direka untuk mengurangkan request berulang.
      

    


    

      Sitemap
      

        Sitemap crawler boleh menemukan sehingga 500 URL dan
        URL tersebut boleh dihantar terus ke Bulk Audit.
      

    


    

      Browser History / Cookies
      

        Website tidak boleh secara umum memadam history, cookies atau
        cache global Safari/Chrome pengguna. Dashboard ini hanya
        mengurus data localStorage miliknya sendiri.
